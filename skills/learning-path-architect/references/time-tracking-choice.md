# Free Android and Windows Time Tracking

Use this reference when the learner wants a free tracker on Android and Windows.

## Practical recommendation

Start with an easy free cross-device tracker such as Clockify or Toggl Track if the priority is simple manual timers and synchronization. These are hosted commercial services rather than fully open-source offline tools.

Evaluate ActivityWatch when privacy, local ownership, and Windows automatic activity tracking matter most. Verify Android support before choosing it as the only cross-device tracker.

Evaluate Kimai with a compatible Android client when open-source ownership and self-hosting matter more than setup simplicity. Kimai is powerful, but it is not the easiest option for a non-technical individual because a server or hosted instance may be required.

Do not build a custom tracker unless the existing choices fail a clearly stated requirement.

## Minimum useful record

A learning time record should contain date, subject, start and stop time or total duration, optional note, and the associated roadmap area. Time is evidence of effort, not proof of mastery; also record observable work or assessment evidence.

## Portability rule

Prefer a tracker that can export data or provide a durable account export. The learning workspace should store a summary or imported record rather than becoming permanently dependent on one vendor.
