# Error-to-Intervention Protocol

Use this reference after a failed milestone, weak transfer result, repeated blocker, or stalled active frontier. Diagnose before expanding the syllabus.

| Observed failure | Likely smallest cause | Smallest intervention | Improvement signal |
|---|---|---|---|
| Cannot explain the idea | Concept gap or misconception | Targeted explanation plus prediction/retrieval check | Accurate explanation without copying |
| Can explain but cannot perform | Procedural fluency gap | Bounded deliberate practice with feedback | Independent completion of a familiar task |
| Performs familiar task but fails a new one | Transfer/discrimination gap | Varied or bounded-unfamiliar task | Correct adaptation with limited support |
| Repeats the same bug | Debugging/error-localization gap | Trace, compare, isolate, and repair one failure | Explains cause and verifies the fix |
| Fast completion but weak retention | Retrieval/spacing gap | Retrieval-first revisit and later transfer | Retention and transfer both improve |
| Cannot start because tools/setup fail | Operational/environment gap | Fix or sandbox the environment | Reproducible setup and first successful run |
| Progress collapses with parallel branches | Overload/switching gap | Narrow concurrency and protect minimum continuity | One primary branch is sustained |
| Evidence is copied, stale, or self-report only | Verification gap | Re-run in an independent or unfamiliar context | Fresh, attributable evidence |
| Effort is available but route is repeatedly blocked | Dependency or task-design gap | Re-audit the smallest prerequisite or redesign task | Blocker disappears without adding unrelated topics |

## Intervention rule

Choose one primary intervention dimension at a time unless evidence shows the causes are coupled. State the expected signal, the support allowed, and the recheck trigger. If the signal does not improve, classify the failure again rather than automatically increasing effort.

Do not infer laziness, intelligence, personality, or motivation from a failed observation. Distinguish route failure, capacity friction, environment failure, evidence failure, and one-off shock.
