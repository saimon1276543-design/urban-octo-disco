# Infrastructure, Virtualization, GPU Systems, and MLOps

Use this reference for Linux infrastructure, QEMU/KVM, GPU clusters, Docker, Nginx, DevOps, MLOps, CUDA concepts, archiving, and media pipelines.

## Virtualization and Linux operations

Cover hypervisors, guests, virtual disks, QEMU/KVM, VM creation, ISO installation, LVM, ZFS, qcow2/raw, bridged/NAT/VLAN networking, CPU pinning, NUMA, hugepages, memory, backups, snapshots, PCI passthrough, live migration, HA clustering, sVirt/SELinux, firewalling, virtio, and performance testing. Use least privilege, change plans, backups, and recovery tests.

## Containers and services

Cover Docker images, reproducible builds, registries, volumes, networks, isolation, resource limits, secrets, health checks, rollback, Nginx reverse proxying, TLS termination, routing, caching, load balancing, logs, and metrics.

## GPU and model systems

Teach accelerator memory hierarchy, kernels, synchronization, profiling, batching, distributed training, inference, CUDA concepts, and capacity planning. Keep hardware, driver, framework, and model compatibility in the current-verification layer. A billion-parameter training goal requires explicit data, compute, memory, network, cost, and evaluation models; never promise feasibility without those inputs.

## DevOps/MLOps and media

Cover Git, CI/CD, artifact and model/data versioning, experiment tracking, deployment, monitoring, drift, rollback, incident response, governance, FFmpeg-based authorized audio/video processing, archiving, hashes, deduplication, retention, and reproducibility.
