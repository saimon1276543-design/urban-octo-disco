# Adaptive Learning Loop

Use this reference when the learner asks how to study, is stuck, needs remediation, or wants a repeatable practice cycle. Keep it separate from the full syllabus.

## Loop

1. Define one objective and the prerequisite assumption.
2. Retrieve or predict before reviewing the explanation.
3. Use a short explanation, example, or reference only for the identified gap.
4. Perform deliberate practice with a visible stopping condition.
5. Inspect feedback and classify the error.
6. Apply the capability in a varied or unfamiliar context when transfer matters.
7. Record evidence, support level, effort, and the smallest gap.
8. Choose advance, reinforce, remediate, maintain, narrow, or re-diagnose.

The loop should end with an observable artifact or performance signal, not just exposure to content. Increase novelty, ambiguity, or independence one dimension at a time. Reduce support gradually for lower levels and increase judgment and trade-offs for higher levels.
