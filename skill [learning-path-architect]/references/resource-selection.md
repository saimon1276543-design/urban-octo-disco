# Resource Selection by Function

Use this reference only when the learner asks where or how to study, or when a specific gap needs an external resource. A resource is justified only when it changes the next action or improves evidence.

## Resource functions

| Function | Use for | Expected evidence |
|---|---|---|
| Explanation | Repair a concept or misconception | Accurate explanation or prediction |
| Reference | Look up syntax, definitions, or constraints during practice | Correct use in an independent task |
| Worked example | Show a pattern before guided practice | Reconstructed solution with reduced support |
| Practice environment | Provide executable repetition or safe experimentation | Reproducible performance or artifact |
| Feedback source | Reveal errors and improve judgment | Corrected work with explained changes |
| Project scaffold | Reduce setup friction for an application | Modified artifact that the learner can explain |
| Assessment instrument | Sample readiness or transfer | Fresh evidence in the intended context |

## Selection record

For each recommended resource record the named gap, function, prerequisite, access/freshness boundary, why it is preferable to a simpler option, and the evidence task that follows. Prefer authoritative or maintained sources, but do not dump links or imply a source was checked when it was not.

## Resource failure

If a resource is inaccessible, too advanced, stale, or not improving the evidence signal, replace the resource or change the intervention. Do not add more resources to compensate for an unclassified failure.
