# Full-Stack, APIs, Databases, and Networking

Use this reference for full-stack systems, JSON, regex, API creation, databases, networking, and production integration.

## Full-stack architecture

Connect browser/frontend, HTTP/API, authentication and authorization, backend services, databases, caches, queues, storage, background jobs, observability, testing, deployment, CI/CD, accessibility, performance, and security. Distinguish an end-to-end demo from independently evidenced production capabilities.

## JSON and regex

Teach JSON values, schemas, validation, encoding/escaping, compatibility, canonicalization, JSON Lines, streaming, limits, and error handling. Teach regex character sets, Unicode, groups, boundaries, quantifiers, lookarounds, engine differences, testing, and performance. Warn about catastrophic backtracking and choose a real parser when grammar, nesting, or maintainability demands it.

## API creation

Cover resource and contract design, HTTP semantics, REST/RPC/event interfaces, GraphQL concepts, pagination, filtering, versioning, validation, errors, idempotency, retries, rate limits, authentication, authorization, webhooks, async jobs, documentation, SDKs, observability, and deprecation. Current framework syntax is volatile.

## Databases

Cover relational modeling, keys, constraints, normalization, transactions, isolation, concurrency, indexes, query plans, migrations, replication, partitioning, sharding, backup/recovery, analytical, document, graph, vector, time-series, and cache systems. Choose based on workload and consistency requirements rather than product fashion.

## Networking

Cover models, addressing, subnetting, routing, switching, DNS, DHCP, ARP, TCP/UDP, TLS, HTTP, proxies, load balancing, firewalls, VPNs, service discovery, sockets, latency, throughput, congestion, diagnosis, and secure design. Require authorization for network changes and testing.
