# Project Progression and Capstones

Use this reference when a learner needs projects, portfolio evidence, integration practice, or a capstone.

## Staged ladder

1. Orientation: bounded demonstration of vocabulary and core concepts.
2. Foundation: one capability with tests and a clear evidence boundary.
3. Integration: two or more domains joined through an explicit interface.
4. Advanced: performance, reliability, debugging, evaluation, and trade-offs.
5. Enterprise/research: scale, observability, governance, recovery, reproducibility, and review.
6. Capstone/contribution: independently scoped work with defense, documentation, and maintenance.

Each project states primary and supporting domains, target capability/level, prerequisites, scope, artifact, rubric, resources, assumptions, safety/authorization, failure modes, exclusions, and what it does not prove.

## Reusable ladders

- DevTools/network debugging → browser crawler → parser/index → hybrid RAG.
- BCI signal preprocessing → neural decoder → human-in-the-loop interface.
- Robotics telemetry → Kalman filtering → database → dashboard.
- MCP server → agent dispatcher → RAG system → browser tool.
- Multi-terabyte cleaning → embeddings/features → search/index.
- LLM training/inference → evaluation → serving → agent application.
- OSINT acquisition → provenance/entity resolution → evidence graph → Graph RAG.

Projects are evidence containers, not proof of every connected skill. A BCI project does not establish clinical competence; a crawler does not establish authorization; an agent demo does not establish safe autonomy; a deployment does not prove production readiness without operational evidence.
