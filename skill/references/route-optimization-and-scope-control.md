# Route Optimization and Scope Control

Use this reference for huge portfolios, route comparisons, what-if questions, and deciding what to skip.

## Route alternatives

When useful, compare minimum viable, research, production-engineering, enterprise systems, medical/clinical-foundation, project-first, and maximum-depth routes. Each route includes target capability, included nodes, deferred/omitted nodes, substitutions, assumptions, critical path, parallel branches, evidence milestones, capacity/resource requirements, risks, reversibility, and smallest next action.

Do not claim a mathematically optimal route when learner capacity, prior evidence, target context, or access is unknown. Use conservative assumptions, qualitative trade-offs, and bounded pilots. Preserve omitted goals in the authoritative coverage ledger with a reason and activation condition.

## Anti-overbuilding rule

For narrow questions, return the relevant graph slice, immediate prerequisite, one primary action, one evidence task, and one review trigger. For massive requests, retain every meaningful goal in the index but show only the active frontier. Add a full architecture only when it changes sequencing, scope, safety, capacity, or route decisions.
