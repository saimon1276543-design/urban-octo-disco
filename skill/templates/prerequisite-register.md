# Prerequisite Confidence Register

Use this template for broad, high-stakes, revised, or disputed maps where inferred prerequisites materially affect scope. Do not add it to a simple narrow map unless the user requests auditability.

## Register

| Added prerequisite | Supports outcome/node | Dependency type | Confidence | Evidence or rationale | Activation condition | If omitted | Decision |
|---|---|---|---|---|---|---|---|
| {{Prerequisite}} | {{Node or outcome}} | {{Conceptual / performance / operational}} | {{High / medium / low}} | {{Specific capability gap or domain evidence}} | {{When this becomes necessary}} | {{Likely consequence}} | {{Required / recommended / optional / omit}} |

## Decision rules

- Mark a prerequisite **Required** only when omitting it creates a credible conceptual or performance gap for the stated outcome.
- Mark a prerequisite **Recommended** when it improves reliability or transfer but the learner can still reach the outcome without it.
- Mark a prerequisite **Optional** when it supports enrichment, specialization, or a different route.
- Mark a prerequisite **Omit** when it is merely adjacent, popular, traditional, or unsupported by the requested outcome.
- For low-confidence items, prefer an entry diagnostic, conditional note, or reversible checkpoint over mandatory scope.
- Revisit this register when the learner’s context, target proficiency, technology choice, or performance evidence changes.
